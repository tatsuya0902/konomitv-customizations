# KonomiTV ローカル改造

[KonomiTV](https://github.com/tsukumijima/KonomiTV) v0.14.1 に対して自宅の録画環境で使っている独自機能のパッチと報告の置き場です。元は [PIX-DT295 調査リポジトリ](https://github.com/tatsuya0902/pix-dt295-investigation) の一部でしたが、量が増えたため分離しました。

- 機能の一覧と索引：[CUSTOM-FEATURES.md](CUSTOM-FEATURES.md)
- 改造の全記録（未公開分を含む、復元用マスター記録）：[LOCAL-CUSTOMIZATIONS.md](LOCAL-CUSTOMIZATIONS.md)

パッチは KonomiTV v0.14.1 の素のツリーに対して `git apply` で適用できます。各パッチの SHA-256 は `SHA256SUMS*` にまとめています。適用順序や詳細は各報告（PLAYBACK.md、RECORDER-FEATURES.md、EPGSTATION-INTEGRATION.md など）を参照してください。
